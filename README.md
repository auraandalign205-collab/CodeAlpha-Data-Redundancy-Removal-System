# 🌊CodeAlpha-Data-Redundancy-Removal-System

A premium, interactive, and beautifully designed **CodeAlpha-Data-Redundancy-Removal-Systemr** web application. This project features state-driven UI themes, interactive dashboard statistics, and smooth animated SVG wave effects that adapt in real time as the counter values change.

## ✨ Features

- **Dynamic State Themes**: The UI seamlessly transitions color schemes based on the current counter value:
  - ✨ **Neutral Point** (Default Gray)
  - 🟢 **Positive Zone** (Vibrant Green for values > 0)
  - 🔴 **Negative Zone** (Crimson Red for values < 0)
- **Live Statistics Dashboard**: Tracks user interactions on the fly:
  - 🔥 **Highest Peak**: Records the maximum value reached.
  - ❄️ **Lowest Dip**: Records the minimum value reached.
  - 📊 **Total Interactions**: Counts every single click/action made.
- **Premium Animations**: Fluid, infinite-scrolling SVG waves combined with tactile button press transitions.
- **Fully Responsive**: Crafted using modern CSS (Flexbox, CSS Variables, and media-friendly structure) to look stunning on mobile, tablet, and desktop screens.

## 🛠️ Tech Stack

- **HTML5**: Structured semantic layout.
- **CSS3**: Custom keyframe animations, UI theme states, and premium glassmorphism elements.
- **JavaScript (Vanilla)**: Clean, optimization-focused state logic and real-time DOM manipulation.

## 📁 Project Structure

```text
├── index.html       # The main HTML structure & SVG markup

```

## 🚀 Quick Start / Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project directory:**
   ```bash
   cd dynamic-wave-counter
   ```
3. **Run the app:**
   Simply double-click the `index.html` file to open it directly in any modern web browser (Chrome, Edge, Safari, Firefox).

## 🎮 How It Works

- Click the **+ Increment** button to increase the value and unlock the *Positive Zone*.
- Click the **- Decrement** button to decrease the value and venture into the *Negative Zone*.
- Click the **Reset** button to wipe all statistics and restore the system to its *Neutral Point*.
